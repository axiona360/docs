# Centro de ayuda de Eclipta

Guía de uso de Eclipta para administradores, supervisores y agentes. Se publica en https://docs.axiona360.com.co.

```bash
npm install
npm start       # ver mientras se escribe
npm run build   # comprobar antes de publicar
```

El contenido vive en `docs/`. Las reglas de escritura están en `CLAUDE.md`.
